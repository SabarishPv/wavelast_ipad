## Third-party services

WaveLast connects only to services you enable:

- LRCLIB, for lyrics.
- Last.fm, using **your own** API account.
- Podcast feeds you subscribe to.
- A Subsonic-compatible server you configure.

WaveLast is not affiliated with any of these services.

## Test assets

No third-party audio is stored in the repository. Tests generate short silent WAV files at runtime.
